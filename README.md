# FIREWORKS ZD – Sitio web institucional

## Qué hace cada archivo
- `index.html`: contenido de la página (textos, secciones). Aquí se editan los textos.
- `css/style.css`: colores, tipografía y diseño. Los colores están al inicio (`:root`).
- `js/script.js`: menú del celular, visor de fotos, formulario. El correo destino está en `CORREO_DESTINO`.
- `assets/logo/logo.svg`: logotipo tipográfico. Reemplazar por otro archivo con el mismo nombre.
- `assets/images/`: fotografías. Solo subir fotos con autorización.
- `README.md`: este archivo.
